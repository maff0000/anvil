# Operating model

`Human + CGPT PID → Axiom PL → ANVIL/GPU → GitHub → CGPT scrutiny`

The Human Product Owner participates in PID creation/start, genuinely
unavoidable product decisions, and final acceptance. Routine technical
questions remain with the PL. The Human must not act as a message courier
between Axiom and CGPT; GitHub issue #1 is the durable communication surface.

ANVIL remains a direct bounded inference harness. Future delivery loops must
preserve mechanical tests, bounded attempts, evidence, and independent
scrutiny.
