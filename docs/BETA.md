# ANVIL beta

This beta proves a thin local-GPU capability harness plus a GitHub-based
Axiom/CGPT communication loop. It introduces no agent runtime, workflow
engine, broker, or production router.

Acceptance requires canonical history published without rewriting; meaningful
checkpoints on issue #1; an Axiom heartbeat; an Axiom query or delivery
candidate; a direct CGPT reply; Axiom consumption of that reply; passing
benchmark tests; isolated evidence; clean reconstructable Git history; and
unchanged production routing.

The beta is complete only after the communication exchange and independent
scrutiny are visible on issue #1.
